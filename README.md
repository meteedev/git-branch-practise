# Todo App

Toy project สำหรับฝึก Git Branching Strategy

## Branch Structure
- `prod`    — production (live)
- `preprod` — pre-production
- `uat`     — user acceptance test
- `develop` — integration branch
- `mvp`     — MVP features
- `feature` — feature branches (แตกจาก mvp)

## การรัน
```bash
node src/index.js
```
